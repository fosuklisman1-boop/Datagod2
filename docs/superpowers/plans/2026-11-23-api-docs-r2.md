# API Docs (Release 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/developers` a professional API reference (page per product, search, Try-it with test keys, sandbox failure numbers, OpenAPI, Copy for AI, go-live guide, starter kits, error guide, changelog) with `registry.ts` as the single source.

**Architecture:** Pure builders in `lib/api-v2/docs/` turn the registry into page maps, a search index, an error guide, OpenAPI and Markdown; thin routes and server pages call them; a shared `app/developers/layout.tsx` carries the sidebar, search and the scoped overflow fix. The existing docs kit (`DocsPage`, `EndpointBlock`) is extended with optional props so `/dashboard/developer` is unchanged. The only API-side change is a v2 sandbox-only outcome marker for two reserved recipient patterns.

**Tech Stack:** Next.js 15 (App Router, `generateStaticParams`), React, TypeScript, Tailwind, Vitest (node environment, `.test.ts` only).

**Spec:** `docs/superpowers/specs/2026-11-23-api-docs-r2-design.md`. Read it with this plan; section numbers below refer to it.

## Review Focus

1. A live key (`dg2_live_`, `dg2_cs_live_`, `dg2_sms_live_`, v1 `dg_live_`) or a key with spaces/newlines pasted into Try-it: refused in the browser, field cleared, zero `fetch` calls. (Task 7)
2. The reserved numbers on a live key, a v1 sandbox key or a non-data product behave exactly as before; a marker never reaches the public order JSON. (Task 2)
3. A new registry section or a new registry error appears with no page or no advice: CI fails instead of the content silently vanishing from the docs. (Tasks 1, 3)
4. An endpoint answers HTML, an empty body or the network drops during Try-it: a labelled text result, no thrown error, no crash; a `{campaign_id}` value with `/`, `?` or `#` stays inside the path. (Task 7)
5. A registry param type the OpenAPI mapper does not know (`string[]`, `Ghana Card`): the document stays valid with a string fallback and the original text kept. (Task 4)
